# Vom Gen zum Protein

Selbstlernseite GK Biologie 11, LB 1 (Evangelisches Gymnasium Lernwelten).

`index.html` ist vollständig eigenständig: Schriften, Stylesheet, Logo und Interaktionen sind eingebettet. Keine Build-Schritte, keine externen Abhängigkeiten.

## Auf GitHub Pages veröffentlichen

1. Inhalt dieses Ordners in ein Repository pushen (Branch `main`).
2. Settings -> Pages -> Source: "Deploy from a branch", Branch `main`, Folder `/ (root)`.
3. Die Seite erscheint unter `https://<benutzername>.github.io/<repo>/`.

Die Datei `.nojekyll` verhindert, dass GitHub Pages den Inhalt durch Jekyll verarbeitet.

## Lokal öffnen

`index.html` im Browser öffnen (Doppelklick genügt).

Der Lernfortschritt (aufgedeckte Loesungen, abgehakte Aufgaben) wird im localStorage des jeweiligen Browsers gespeichert.
